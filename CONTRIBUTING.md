# Contribuire al Sistema Gestionale Ristorante

Grazie per l'interesse nel contribuire al progetto! 🎉

## 🤝 Come Contribuire

### Segnalazione Bug
1. **Verifica** che il bug non sia già stato segnalato.
2. **Apri** una nuova issue con:
    - Descrizione dettagliata del problema
    - Passi per riprodurre il bug
    - Screenshot se necessario
    - Informazioni su distribuzione Linux e versione Bash

### Richieste Funzionalità
1. **Apri** una issue con label "enhancement".
2. **Descrivi** la funzionalità richiesta.
3. **Spiega** il caso d'uso.
4. **Proponi** una possibile implementazione.

### Pull Request
1. **Forka** il repository.
2. **Crea** un branch per la tua feature: `git checkout -b feature/nuova-funzionalita`
3. **Commita** le modifiche: `git commit -m 'Aggiunge nuova funzionalità'`
4. **Push** al branch: `git push origin feature/nuova-funzionalita`
5. **Apri** una Pull Request descrivendo chiaramente le modifiche.

## 📝 Standard di Codice

### Bash
- Usa **indentazione a 4 spazi**
- **Commenta** sezioni complesse o comandi non ovvi
- Segui le **best practice** per la scrittura di script Bash
- Usa **nomi di variabili chiari** e significativi
- Gestisci **errori** e casi limite

## 🧪 Testing

### Test Manuali
- Testa su **diverse distribuzioni Linux** (es. Ubuntu, Fedora, Arch)
- Verifica la compatibilità con **diverse versioni di Bash**
- Controlla il comportamento in **ambienti diversi** (locale, server, container)
- Testa gli script con **input vari e casi limite**

### Checklist Pre-Pull Request
- [ ] Il codice funziona correttamente
- [ ] Nessun errore in output/console
- [ ] Compatibilità cross-distribuzione e cross-versione Bash
- [ ] Documentazione aggiornata
- [ ] Commit messages descrittivi
